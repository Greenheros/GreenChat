Comment obtenir un Client ID ?
  1. Va sur dev.twitch.tv/console/apps → Enregistrer votre application.
  2. Nom : ce que tu veux (ex. GreenChat Maxime). URL de redirection OAuth : http://localhost.
  3. Catégorie : Chat Bot. Type de client : Public (important).
  4. Copie le Client ID ici, enregistre, puis clique sur « Se connecter avec Twitch ».

Sans connexion, le chat s'affiche quand même en lecture seule (pas d'envoi, pas de modération, pas de follows/points).

🔧 Ton appli Twitch

Pour écrire, modérer et recevoir les follows, GreenChat a besoin d'un Client ID. C'est gratuit et ça se crée une seule fois :

  1. Ouvrir la console Twitch ↗ (connecte-toi si besoin)
  2. Nom : ce que tu veux, par exemple GreenChat perso
  3. URL de redirection OAuth : http://localhost
  4. Catégorie : Chat Bot · Type de client : Public important
  5. Clique sur Créer, puis sur Gérer : copie le Client ID et colle-le ci-dessous.
